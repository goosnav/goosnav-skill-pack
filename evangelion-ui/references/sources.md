# Reference provenance and further study

Primary visual evidence: the seven user-supplied frame/still/GIF references bundled in `screens/`. Use them as visual references, not runtime backgrounds. They include different resolutions and transfer treatments; individual production/version provenance was not verified. Colors and CSS values in this skill are authored approximations.

Broader references consulted on 2026-09-10:

- [Evangelion Commentary Project, Episode 13 Scene 07](https://wiki.evageeks.org/FGC:Episode_13_Scene_07), especially [Cut 226](https://wiki.evageeks.org/FGC:Episode_13_Cut_226): operation proposals and contextual computer displays. This is a fan-maintained reference with scene transcriptions; distinguish its commentary from source-film imagery.
- [Episode 01 Scene 07](https://wiki.evageeks.org/FGC:Episode_01_Scene_07): command-room startup context. Use real operation phases rather than importing show terminology into products.
- [Magi overview](https://wiki.evageeks.org/Magi): pointers to Episode 13 and The End of Evangelion, plus the three-part decision display. This page carries an accuracy warning; do not use its unverified lore as factual product copy.
- [Additional MAGI defense screen reference](https://x.com/Nerv2015AD/status/682422536462700544), [image](https://pbs.twimg.com/media/CXhzrhbUkAA6LAy.png): wider defense/topology vocabulary beyond the supplied close-ups. Search imagery is contextual reference, not verification of every image caption or number.
- [The End of Evangelion handheld MAGI screen](https://www.imdb.com/media/rm3282362369/tt0169858): additional search-indexed reference for compact decision controls. Do not infer an entire movie's design system from one still.
- [Claude Code skills documentation](https://code.claude.com/docs/en/skills): standard SKILL.md and relative supporting folders, project and personal skill installation paths.

The requested [Bagus Indrayana X post](https://x.com/bagusindrayana_/status/2097889948871618862) could not be retrieved. Do not claim to have inspected its text or linked code. The skill remains usable offline via bundled references and authored guidance.

This is a visual-language synthesis spanning analytical, resource, approval, operational, spatial and editorial treatments, not an exhaustive frame-by-frame catalog of the show or an official asset/font collection. Additional research can refine a specific requested scene; do not delay ordinary implementation for unnecessary exhaustive browsing.

Bundled font: [Barlow Condensed, Google Fonts source](https://github.com/google/fonts/tree/main/ofl/barlowcondensed), `BarlowCondensed-Bold.ttf` and accompanying `OFL.txt`. This is an open-font implementation choice, not a claim of original Evangelion font identity.
